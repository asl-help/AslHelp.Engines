## [Unreleased]

### Added
- `AslHelp.Engines` with `IMemberPath`, the path contract an engine library implements. Its `Member`, `Item`, `Count` and `Value<T>` steps return a `Result`. `Read()` and `Read<T>()` read the value once without a watcher. `IsChecked` is false for a step the engine couldn't check yet and `MemberPathError.IsShapeMismatch` is true for a path that doesn't fit the classes of the game. `PathKey` is an index or key and `StructValue` is a struct by member name. Extension members on `Result<IMemberPath>` chain the steps.
- `IWatcherSource` and `IWatcherSource<T>` in `AslHelp.Engines` for an object that a host can create a watcher from.
- `AslHelp.Engines.Unreal` with `ObjectReader`, `StructReader` and `IPropertyReader` for reading names, objects, structs and properties from Unreal Engine 3, 4 and 5 games. The caller picks the storage shape with `FlatNameTable`, `IndirectNameTable` or `ChunkedNameTable` behind `INameTable` and `PointerObjectArray`, `IndirectObjectArray`, `ItemObjectArray` or `ChunkedObjectArray` behind `IObjectArray`. For properties it picks `ObjectPropertyReader` through 4.24 or `FieldPropertyReader` from 4.25 behind `IPropertyReader`. It passes the offsets as layout records.
- The readers return `Result<T>`. A failed read has the address, the layout field to check and the cause in its message. `IObjectArray.Read` gives a failure in place of each pointer that doesn't read, so 1 unreadable block or chunk doesn't hide the objects behind it.
- `UnrealProfile.Parse` in `AslHelp.Engines.Unreal` reads the `unreal3` and `unreal4` profile documents of the `measure` tool. A document with missing offsets or globals fails with all of them in 1 message.
- `UnrealGame.Attach` finds the globals of a profile in a running game and builds the readers for its shapes. `UnrealGame.GWorld` is the root at the world. A `GWorld` or `GEngine` that isn't found doesn't fail attach. A read through it fails and searches the module again after 1 second.
- `UnrealGame.ClassOf` returns the real class of an object and `UnrealGame.FindClass` finds a loaded class by name. `UnrealClass.FindProperty` finds a property on the class or one of its super classes. `FindClass` and `FindProperty` ignore case, but the exact name wins.
- `game.GWorld.Path` is an `UnrealPath`, which implements `IMemberPath`. When the object is there, a step fails at once on a member the class doesn't have or on a wrong `T`. When it isn't, the step checks the classes that the properties declare and fails on a member that neither the declared class nor a loaded derived class has. That step can pass once the game loads more classes. Each read looks the member up on the real class of the object and goes through an object pointer or into a struct by the kind of the property. The boxed `Watcher<object?>` of a path gives the value in the type of the property it finds at read time.
- Paths and `UnrealGame.Read<T>` read the 9 number properties, `ByteProperty`, `BoolProperty` with bitfields, `EnumProperty`, `NameProperty`, `StrProperty` and the object properties. Paths also go into a `StructProperty`. A profile without the offsets of a kind still attaches and only reads of that kind fail.
- `UnrealGame.Read<T>` reads the value of 1 property. `UnrealProperty.Accept` passes a property to a `PropertyVisitor<TResult>`, which gets `VisitValue<T>`, `VisitEnum`, `VisitStruct`, `VisitCollection` or `VisitUnsupported`.
- Paths and `UnrealGame.Read<T>` read `ArrayProperty` as an array, `SetProperty` as a `HashSet<T>` and `MapProperty` as a `Dictionary<TKey, TValue>`. `UnrealPath.Item(key)` goes into 1 element and `UnrealPath.Count` reads the number of elements. On a set of objects or a map keyed by objects the key is the position among the used items. A whole read fails above 1024 elements and a key lookup above 1024 slots. `ValueBounds` passed to `UnrealGame.Attach` sets other limits for strings and collections.
- `WeakObjectProperty` reads as the `Address` of its object or 0 when the serial number of the item doesn't match. Before 4.11 it reads the serial numbers from the blocks of `GSerialNumberBlocksForDebugVisualizersRoot`, a global of the documents of those versions. `ProfileReader.ReadGlobalOrNull` reads a global that a document doesn't need to have. `IObjectArray.ReadItem` returns the object and the serial number at an index and `ObjectItemLayout` takes the offset of the serial number.
- A `StructProperty` reads as a `StructValue` with its members by name, both from a boxed watcher and from `Value<StructValue>()`. One whose members are all numbers of 1 class, like `FVector`, also reads as an array of that number. `FVector` and `FRotator` also read as `Vector` and `Rotator` with doubles on every version. `LargeWorldCoordinatesRealProperty` reads as `double`.
- `UnrealGame.GEngine` is the root at the engine object. A profile document needs `globals.GEngine`.
- `UnrealGame.FindPackage` and `GetPackages` find loaded packages. `UnrealPackage` has `FindClass` and `GetClasses`. `UnrealClass` gets `Properties`, `GetInstances` and `GetDerivedClasses`.
- `UnrealObject` is a live object from `GetInstances` with a `Path` that starts at it.
- `UnrealGame.FindSubsystem` returns an `UnrealRoot` at the subsystem of a class in the subsystem map of the game instance on 4.22 or later.
- `ProfileCatalog<TProfile>` in `AslHelp.Engines` picks the profile document for a `ProfileTarget` of any engine. The engine passes its mapper and its version parser, which gives the numbers of a `ProfileVersion`. `Select` takes the document that lists the version, its line or a version that starts with it, like 5.8.4 for 5.8. `ProfileGuessHandling.Allow` guesses the nearest patch of the same minor or the highest lower version of the same major with a `Warning`. `Disallow` fails with the version a guess would take. A document added later wins, so a consumer document replaces a shipped document. `ProfileReader` reads the parts every document has for the mapper of an engine and fails a document with a root key that the reader and the mapper don't read or an unread offset in a type that misses an optional offset.
- `AslHelp.Engines.Unreal` ships the measured documents of 4.0 to 5.8 and UDK 2010-06 to 2015-02. `UnrealProfile.CreateCatalog` returns a catalog with them.
- `UnrealTarget.Detect` reads the engine version from the executable and builds the key like `win-x64-shipping`. A caller can pass the version and the configuration instead. `UnrealTarget.ParseVersion` reads a version like 4.27.2, 2010-09 or 3.8225. An Unreal Engine 3 build without a measured UDK release reads as 3 and the build, so guessing takes the nearest lower UDK document.
- `TickMemo<T>` in `AslHelp.Engines` keeps 1 value for 1 tick of 1 tick counter, so an engine can read the shared steps of paths once per tick.
- Path watchers with the same tick counter read the steps their paths share and the class of the object each step reaches once per tick, so 30 watchers under `GWorld.GameMode.Data` cost 39 reads per tick instead of 300. Paths built apart from the same root share them too. `FindSubsystem` returns the same root for the same class name. The root keeps every path a step returned, so build paths once.
- `UnrealGame.Attach(memory, module, guessHandling)` and `Attach(memory, module, catalog, guessHandling)` detect the target and pick a document. They and the overload with a selection check that name 0 reads `None`. A document that doesn't fit fails with the detected version. `UnrealGame.Profile` and `UnrealGame.Selection` show what attach used.
